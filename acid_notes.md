- Add players

- Start game

        - Out value
    - Start

        - each row for a player 
        - columns for each round
        - first column shows player names
        - seconds column shows sum of scores
        - further columns for each round
        - easy options to enter scores and edit
- Continue game
    - List all old games with option to continue them
- Insights
    - Player with most no of games
    - Player with most high scores
